## Is Force Graph / Knowledge Graph Actually Useful?

**Yes, but for specific things:**

| Use case | Force graph helps? |
|---|---|
| "What connects to X?" | Yes — follow edges visually |
| "What are the major themes?" | Yes — clusters reveal communities |
| "Find a specific node" | No — search is faster |
| "How many nodes of type Y?" | No — a table or chart is better |
| "Are there hub nodes?" | Yes — size-by-degree makes them obvious |

For your DB specifically: the value is showing *which AI projects share organizations/categories* without anyone having to query it. The visual pattern IS the insight.

## How Cosmograph Creates Clusters

Same physics as your vis-network, but the **visual result looks better** because of how they tune and render it:

1. **Gravity toward cluster centroid** (not just global center) — once a community starts forming, a weak inward pull keeps it cohesive without collapsing it
2. **Strong inter-node repulsion** — pushes unconnected groups apart so white space forms between clusters
3. **Long springs** — connected nodes stay far enough apart that you can see the edges, not just a blob
4. **GPU rendering** — 60fps at 78k nodes means you can watch it settle in real time, which is itself informative

This is basically identical to your current barnesHut setup — the physics principle is the same.

## What Cosmograph Has That Your Explorer Doesn't (Visually)

| Feature | Cosmograph | Your explorer |
|---|---|---|
| **Node glow / bloom effect** | Yes (WebGL post-processing) | No |
| **Edge color = source node color** | Yes, with opacity falloff | Flat gray |
| **Dark background** | Yes — makes colors pop | Light/mixed |
| **Node size encodes degree** | Yes by default | Fixed size |
| **Timeline scrubber** | Yes (linked histogram) | No |
| **Lasso select** | Yes | Partial |
| **Cluster label overlays** | Yes (computed, float above) | No |
| **GPU rendering** | Yes (WebGL) | No (DOM/SVG via vis-network) |
| **Density-based opacity** | Dense areas fade edges, sparse pop | All edges same weight |

The single biggest visual difference: **edge opacity proportional to node degree**. Dense hubs have faint edges (otherwise it's a hairball); peripheral nodes have bold edges. This is what makes the "galaxy" look instead of a mudball.

## How Obsidian Local Graph Works

You open a note → right-click → "Open local graph." The graph shows:
- **Depth 1**: only notes directly linked to/from this note
- **Depth 2**: those notes' neighbors too
- **Slider**: you drag it from 1 to 4 hops — the graph expands outward in real time
- **Toggles**: show/hide incoming links, outgoing links, "neighbor links" (edges between non-focal nodes)

The cognitive model is **ego-network exploration** — you're always centered on one node and exploring outward. This is very different from the global view. For your DB, an equivalent would be: click a project → graph collapses to show only that project's org, categories, and their other projects.

---

## How Sigma.js Demos Handle Sizing and Clusters

The [Sigma.js demo](https://www.sigmajs.org/demo) uses **Graphology** under the hood:
1. **Community detection**: runs Louvain algorithm on load → assigns each node a `community` integer
2. **Node color**: mapped from community ID → each cluster gets a distinct hue
3. **Node size**: mapped from degree (edge count) → hubs are visually large, leaves are tiny dots
4. **Layout**: ForceAtlas2 run offline, positions baked into the data file — so the graph loads pre-settled into clusters, no physics needed at runtime
5. **Interaction**: hover a node → all non-neighbor edges fade to ~5% opacity (neighbor highlighting)

The degree-based sizing + community coloring combo is what makes it immediately readable — you can see hierarchy (big hub vs. small leaf) AND grouping (same color = same cluster) at a glance.

---

**Bottom line for your project**: the two highest-ROI improvements based on all of this would be (1) size nodes by their edge count and (2) fade edge opacity for high-degree nodes. Those alone would make it look dramatically more like Cosmograph/Sigma without changing the physics at all.
